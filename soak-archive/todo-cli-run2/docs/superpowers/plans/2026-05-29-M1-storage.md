# M1-storage: TDD Implementation Plan

Milestone: Storage layer for todo-cli
Date: 2026-05-29
Scope: Todo model + JSON file storage with atomic writes + CRUD operations

## Overview

Build the storage foundation: a Todo data model and a JSON-backed store that
supports add, list, done, and remove operations. All file I/O uses atomic writes
(write-to-tmp-then-rename) and the store file is created with 0o600 permissions.

Per milestone definition, implementation lives in a single file `todo/storage.py`
with tests in `tests/test_storage.py`. The Todo dataclass is defined inside
`storage.py` (no separate models module).

This milestone does NOT include the CLI layer — only the Python API that the CLI
will call.

## Storage schema

```json
{"next_id": 1, "todos": []}
```

The `next_id` counter ensures IDs are never reused, even after all todos are
deleted. Each todo is `{"id": int, "text": str, "status": str, "created_at": str}`.

## Prerequisites

- Python 3.11+
- No external runtime dependencies (stdlib only)

### Task 21: Test — Edge cases, error paths, and crash resilience

**What:** Add edge-case and error-path tests:
- Empty text is allowed (spec doesn't prohibit it)
- Very long text is stored correctly
- Store file with extraneous JSON fields handled gracefully (via from_dict)
- Multiple save/load cycles maintain data integrity
- Corrupted/invalid JSON in store file raises a clear error
- Atomic write does not corrupt existing data on write failure (mock the tmp
  write to fail, verify original file intact)

**Test first:**
```python
def test_empty_text(tmp_path):
    store = TodoStore(tmp_path / "store.json")
    t = store.add("")
    assert t.text == ""

def test_long_text(tmp_path):
    store = TodoStore(tmp_path / "store.json")
    long = "x" * 10000
    t = store.add(long)
    loaded = store.load()
    assert loaded[0].text == long

def test_extra_json_fields_ignored(tmp_path):
    store_path = tmp_path / "store.json"
    data = {"next_id": 2, "todos": [
        {"id": 1, "text": "a", "status": "open",
         "created_at": "2026-01-01T00:00:00+00:00", "extra": "field"}
    ]}
    store_path.write_text(json.dumps(data))
    store = TodoStore(store_path)
    todos = store.load()
    assert len(todos) == 1

def test_corrupted_json_raises(tmp_path):
    store_path = tmp_path / "store.json"
    store_path.write_text("not valid json{{{")
    store = TodoStore(store_path)
    with pytest.raises((json.JSONDecodeError, ValueError)):
        store.load()

def test_atomic_write_preserves_data_on_failure(tmp_path, monkeypatch):
    store_path = tmp_path / "store.json"
    store = TodoStore(store_path)
    store.add("original")

    def bad_write(*a, **kw):
        raise OSError("disk full")
    monkeypatch.setattr("builtins.open", bad_write)

    with pytest.raises(OSError):
        store.save([Todo(id=99, text="corrupt")])

    monkeypatch.undo()
    loaded = store.load()
    assert len(loaded) == 1
    assert loaded[0].text == "original"
```

**Files:** `tests/test_storage.py`

## Risks and mitigations

| Risk | Mitigation |
|------|-----------|
| File permissions on Windows | Skip permission tests with `@pytest.mark.skipif(os.name != "posix")` |
| Atomic rename across filesystems | Write `.tmp` in same directory as store file |
| ID reuse after deletion | Persistent `next_id` counter in JSON schema, never decremented |
| `os.replace()` on Windows | Atomic on NTFS same-volume; acceptable for single-user CLI |
| Corrupted store file | `load()` lets `json.JSONDecodeError` propagate; existing file intact via atomic writes |
