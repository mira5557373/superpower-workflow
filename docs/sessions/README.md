# Session reports

Working notes / overnight session reports / deep-review findings — kept
out of the repo root so the source tarball stays tidy and `git archive`
output is minimal.

## Convention

- `OVERNIGHT-YYYY-MM-DD.md` — overnight automated-session summary
- `REVIEW-REPORT-YYYY-MM-DD.md` — workflow-driven deep-review findings
- `AUDIT-YYYY-MM-DD.md` — manual audits

New session reports always land here, never in the repo root.
